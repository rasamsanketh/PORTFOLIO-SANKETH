# Rasam Sanketh - Interactive Developer Portfolio

A futuristic, glassmorphic developer HUD (Heads-Up Display) and interactive single-page portfolio website showcasing systems programming and full-stack capabilities.

🚀 **Live Deployment:** [rasamsanketh.github.io/PORTFOLIO-SANKETH/](https://rasamsanketh.github.io/PORTFOLIO-SANKETH/)

---

## Immersive Interactive Applications

This portfolio houses functional in-browser application simulations running on client-side JS:

### 1. 🖥️ Memory OS Simulator
A visualizer for memory management strategies:
- **RAM Grid Map:** Live 128-block occupancy grid.
- **Allocation Rules:** Toggle between **First-Fit**, **Best-Fit**, and **Worst-Fit** models.
- **Process Manager:** Allocate custom threads with variable sizes and time-to-live (TTL) decays.
- **Compaction Engine:** Perform defragmentation to coalesce dispersed free blocks.

### 2. 🧠 AI Neural Network Trainer
A Multilayer Perceptron neural classifier:
- **Visual Nodes:** Nodes glow and weights pulse/resize based on active parameters.
- **Backpropagation Engine:** Trains binary models (XOR gate, Circle cluster, Spiral) in real-time.
- **Decision Boundary:** Live canvas plotting the decision boundary grid dynamically.

### 3. 🐚 Developer Terminal
Interactive mock terminal command line shell supporting standard console operations (`help`, `neofetch`, `skills`, `projects`, `contact`, `clear`, `matrix`).

## Technology Stack

- **Structure:** Semantic HTML5
- **Styling:** Custom CSS Custom Properties (Variables), backdrop filters, neon glow transitions
- **Logic:** Vanilla ES6+ Javascript (Canvas, Backpropagation, Memory fit algorithms)
- **Deployment:** GitHub Pages & Actions workflow pipeline
